# 005 — M1 build log and environment-forced amendments

Status: M1 in progress → shipped for review. Documents judgment calls made
autonomously during the M1 build (2026-08-05).

## Environment constraints discovered (sandbox network policy)

- **npm registry is blocked** (403 policy denial, both direct and via
  proxy). Consequence: the planned Vite + TypeScript toolchain can't run
  here. **Amendment to spec §3.1: the site is a zero-build static app** —
  vanilla JS ES modules, no bundler, no package.json. MapLibre GL JS
  v5.24.0 is vendored into `site/vendor/` (fetched from jsDelivr, which IS
  reachable). Pages serves `site/` as-is; the deploy workflow uploads the
  directory without a build step. TypeScript's benefits are partially
  recovered with JSDoc where it matters. Revisit only if the app grows
  past what a no-build setup handles comfortably.
- **tiles.openfreemap.org is blocked from the sandbox** (fine in
  production — users' browsers fetch tiles directly). Consequences: local
  testing uses a blank-background fallback style, which doubles as
  resilience if the basemap host is ever down; `?basemap=none` URL param
  forces it. Visual verification of the basemap integration happens on the
  deployed site.
- **Overpass API works** (with mirror fallback — overpass-api.de was
  overloaded; kumi.systems/private.coffee mirrors added, plus a local
  cache in `pipeline/cache/`).
- Headless Chromium (pre-installed) renders MapLibre fine with
  `--use-angle=swiftshader-webgl`; used for build-time visual checks.

## SF grid generation (M1 flagship)

Method: 20 hand-chosen arterial corridors (10 EW, 10 NS — Geary, Fulton,
Judah, Taraval, Ocean–Geneva, California, Union, Market, 16th, 24th;
Sunset, 19th Ave/Park Presidio, Masonic, Divisadero/Castro, Fillmore,
Van Ness, Mission, 3rd St, Potrero, Embarcadero). Real geometry from OSM
via Overpass; each street collapsed to a centerline (principal-axis
bucketing at 60 m, robust to dual carriageways), multi-street corridors
joined end-to-end, light smoothing. Stations at corridor crossings
(named "X & Y"), plus infill stations where gaps exceed ~1.4 km
(placeholder names like "Geary 2" — M2 snaps these to real cross-streets
and POIs). Result: 20 lines, 100 stations.

Known M1 limitations (deliberate, for review-then-refine):
- Tier-2 Bay Area lines use straight station-to-station segments;
  corridor-following tracing is an M2 job.
- Tier-3 geometry is coarse hand-placed waypoints (Pacheco, Grapevine).
- SF corridor set is a first draft — expect adds/moves after review
  (e.g. a Richmond-district NS line between Park Presidio and Masonic;
  Bayview/Excelsior coverage is thin).
- No Marin/Golden Gate geometry care yet; RX North Bay crosses the Gate
  as a straight line (a bored crossing is proven tech — Marmaray-class;
  logged for the magic-tunnel-vs-proven ledger discussion in M2).

## Site shell

MapLibre + OpenFreeMap (liberty style), Okabe-Ito colorblind-safe tier
colors (HSR #D55E00, regional #0072B2, metro #009E73), per-tier zoom
thresholds so city grids don't clutter the state view, station popups
with serving lines, layer toggles. Verified via headless screenshot:
layers render, toggles work, no console errors.
