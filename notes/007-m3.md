## Environment findings (sandbox network policy)

- **pip/PyPI: blocked** (like npm). Pipelines are stdlib + requests only.
  Consequence: OSM PBF parsing uses a hand-written pure-Python decoder
  (pipeline/osm_pbf.py) — the format is just varints + zlib blocks.
- **Geofabrik: reachable.** california-latest.osm.pbf (~1.2 GB) downloads
  fine; cached in pipeline/cache/ (gitignored).
- **Census API: now requires an API key** → not used. Anchor place
  populations come from OSM place nodes' population tags instead
  (single data source; missing tags get type-based defaults).
- **All direct agency GTFS hosts are proxy-blocked** (511, agency sites,
  gitlab, trillium, transitland). Reachable instead: raw.githubusercontent
  (LA Metro publishes feeds there) and — decisively — **data.ca.gov /
  caltrans-gis ArcGIS services** carrying Cal-ITP's statewide derived
  datasets: CA Transit Stops (coords, n_arrivals, n_hours_in_service,
  routes served), CA Transit Routes (shapes, n_trips, route_type), and
  Average Transit Speeds by Route × time_period (peak/offpeak).

## AMENDMENT to spec §3.3 (2026-08-05): current transit model

RAPTOR-over-GTFS is replaced by a **frequency-based statewide graph**
built from Cal-ITP's derived datasets: stops joined to routes, stop
sequence inferred by projection onto route shapes, in-vehicle time from
per-route average speed (peak and offpeak variants), boarding wait =
headway/2 (headway from n_arrivals / n_hours_in_service, capped), walk
transfers between stops ≤ ~300 m, walk access/egress ≤ 2 km. Rationale:
raw stop_times are unreachable from this sandbox; the frequency model
gives uniform statewide coverage from one maintained source and matches
the "not obviously wrong" accuracy bar. Bonus: transit gets honest
peak/off-peak variants like driving. Documented tradeoff: no timed
transfers or schedule alignment — acceptable at comparison-site fidelity.

## Design decisions so far

- Road graph: filtered OSM highways — motorway/trunk/primary/secondary
  statewide + tertiary within the nine tier-1 city bboxes; per-class
  speeds with urban adjustments; turn costs folded into per-class speed
  calibration rather than modeled per-intersection (first pass).
- Anchors: OSM place=city|town|village nodes (pop ≥ ~1,000 or type city/
  town), all tier-2/3 fantasy stations, commercial airports (hand list),
  current-transit rail/BRT hubs (once GTFS lands).
- Calibration: ~30 OD pairs with real-world drive times from general
  knowledge (documented as estimates, tolerance ±15% median).
